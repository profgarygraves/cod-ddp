Web, UX & Games

UX and web designers make websites and apps that are easy and enjoyable to use. Game designers build playable worlds. You'll learn user research, prototyping, HTML and CSS, and game engines.

Careers: UX designer, web designer, front-end developer, game designer

What you'll learn

The knowledge, skills, and abilities each program builds. Open a program to see its list.

ASInteraction Design

Knowledge

What you'll understand

  • User experience and information architecture
  • Accessibility law and standards (Section 508, ADA, WCAG)
  • How generative AI works, and its legal and ethical limits
  • Web technologies and programming basics
  • Social media platforms and content strategy

Skills

What you'll be able to do

  • Wireframe, prototype, and usability-test digital products
  • Build websites with HTML, CSS, and a content management system
  • Create accessible documents and content
  • Use generative AI tools in a creative workflow
  • Design typography and visuals for screens

Abilities

How you'll use it on the job

  • Design user-centered websites and apps from research to launch
  • Work with clients, price projects, and manage freelance work
  • Contribute to a team in a real workplace through work experience
CAWeb Design

Knowledge

What you'll understand

  • Web usability, interface, and information design
  • Front-end web technologies
  • Social media platforms
  • Programming basics in Python

Skills

What you'll be able to do

  • Design and build websites with HTML, CSS, and a content management system
  • Research, prototype, and test user experiences
  • Create and optimize images for the web
  • Photograph products and people for web use

Abilities

How you'll use it on the job

  • Plan, build, and launch a website for a client
  • Run a freelance web design business
CAGame Design & Development

Knowledge

What you'll understand

  • The history of games and game genres
  • Game design theory and player experience
  • Legal and ethical issues in game development

Skills

What you'll be able to do

  • Prototype playable 2D and 3D games in game engines
  • Animate characters and model in 3D
  • Storyboard game stories and pitches
  • Playtest and improve a game
  • Write basic code in Python

Abilities

How you'll use it on the job

  • Pitch a game concept and build a playable prototype
  • Work on a game development team

Careers

UX and web designers research what people need, then design and test websites and apps that are easy to use. Game designers plan the rules, worlds, and art that make a game fun. Many roles mix design with front-end code.

"Typical entry education" is what most people in the job have. Creative employers hire from portfolios, so a COD certificate plus strong work can start your career, and a transfer degree keeps the bachelor's option open. UX and web design pay is highest in California's large metros, and many jobs are remote.

Career ladder

  1. Start

    UX intern, junior web designer, QA or playtester

  2. Grow

    UX designer, web designer, front-end developer, game designer

  3. Lead

    Senior or lead UX designer, product designer, design manager

Where the jobs are

  • Tech companies and startups, often remote
  • Marketing and web agencies
  • Colleges, cities, and health systems
  • Game studios
  • Hospitality and real estate companies
  • Freelance web design for local businesses

Skills employers want

  • User research, wireframes, and prototypes
  • HTML, CSS, and Python basics
  • Usability testing
  • Accessibility (WCAG)
  • Game engines and playtesting
  • A case-study portfolio

Transfer

19 of the 19 DDP courses on this path transfer to the CSU, and 11 also transfer to the UC. Each university decides which courses count toward its major, so check ASSIST.org and meet with a counselor.
