Web, UX & games

UX and web designers make websites and apps that are easy and enjoyable to use. Game designers build playable worlds. You'll learn user research, prototyping, HTML and CSS, and game engines.

Careers: UX designer, web designer, front-end developer, game designer

$34.81median hourly pay for web developers in the Inland Empire and Coachella Valley

More careers and pay

Start with DDP 151

User research, information architecture, prototyping, and usability testing. It counts toward the programs on this path, so you can try the field before you commit.
